# Security scope

Do not include credentials, private run state, source payloads or sensitive logs
in public issues. Report security concerns privately to the repository owner
through an established private channel; do not assume a new reporting service.

This package candidate provides version/help only. It supplies no confinement,
PII processing, runtime authority or installation approval. Same-account/process
compromise is not addressed by archive checks. Packaging inventory validation
checks artifacts before installation; it is not a signature or owner approval.
