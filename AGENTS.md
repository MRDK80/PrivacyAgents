# Agent policy

Read CONTRIBUTING.md before changing this project. E2 is packaging only.
Do not introduce runtime activation, grants, target binding or PGW product code.
Keep provenance and MIT notices. Never publish private state/payload/credentials.
One causal issue per task PR into its roadmap, never task directly into main.
Owner approval is required for merge and issue closure; final main merge is separate.
Full pytest, Ruff, mypy and pre-commit gates are required even for documentation.
Use independent controller review and exact PR/postmerge primary CI evidence.
Preserve STOP, original identity/counters/deadlines and UNKNOWN reconciliation.
Never retry external writes because of silence. Monitor processes to terminal.
